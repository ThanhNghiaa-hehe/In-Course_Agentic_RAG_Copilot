### E. Thẩm Định Lý Thuyết Cơ Sở Dữ Liệu: Polyglot Persistence (Vector DB vs SQL)
- Làm rõ bản chất lý thuyết hệ quản trị CSDL:
  1. *Vector Database (Qdrant):* Đóng vai trò **Semantic Indexing Engine** tối ưu cho tìm kiếm xấp xỉ xác suất (ANN, Cosine Distance, HNSW) với độ trễ thấp ($< 10\text{ms}$). Không hỗ trợ giao dịch ACID, không hỗ trợ `JOIN`, không hỗ trợ tính toán số học tổng hợp.
  2. *Relational Database (SQL - PostgreSQL / MySQL / Oracle):* Đóng vai trò **Single Source of Truth (SSOT)** bảo chứng tính toàn vẹn giao dịch (ACID tuyệt đối) cho tài khoản, phân quyền, hạn mức token, xác thực tiến độ học tập thực tế và nhật ký kiểm toán sư phạm (`CHAT_QUERIES`).
  3. *Xu hướng hội tụ:* Liên hệ trực tiếp với đề tài Đề tài 22 HUFLIT (Oracle Database 23ai AI Vector Search) khi tích hợp native `VECTOR` trực tiếp vào bảng quan hệ SQL.
