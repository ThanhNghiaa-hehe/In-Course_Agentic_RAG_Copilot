### 3. 🛠️ Khó khăn kỹ thuật & Giải pháp (Technical Challenges & Mitigations)
1. **Hiện tượng giật/đè dòng chữ trên Windows PowerShell:**
   - *Nguyên nhân:* Các emoji 2 ô (`🎬`, `📌`, `📝`) kết hợp với ký tự lạ gây lỗi tính sai tọa độ X trong Windows conhost buffer, khiến dòng dài bị ghi đè lên các dòng mốc thời gian phía trên.
   - *Giải pháp:* Thay thế hoàn toàn bằng tiền tố chuẩn ASCII (`>>> [CONTEXT 1]`, `- Video:`, `- Moc thoi gian:`) kết hợp `textwrap` ngắt dòng tối đa 72 ký tự và `flush=True`.
2. **Nguy cơ tăng chi phí API khi dọn dẹp văn phong transcript:**
   - *Phân tích:* Nếu dùng Two-pass LLM (1 LLM dọn dẹp + 1 LLM trả lời) sẽ tốn gấp đôi tiền và tăng 2s độ trễ.
   - *Giải pháp:* Gộp chung nhiệm vụ vào System Prompt của LLM duy nhất ở Stage 10, vừa giữ nguyên chi phí rẻ (~0.00006 USD/lượt), vừa đạt văn phong sư phạm tự nhiên.
