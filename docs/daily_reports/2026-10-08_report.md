- **Nâng Cấp Khung Trợ Giảng Thu Gọn (Collapsible Chat Panel):**
  - Bổ sung nút thu gọn trên thanh tiêu đề (`#header-chat-toggle`) và nút nổi thông minh Floating Action Button (`#chat-fab-toggle`) ở góc phải dưới màn hình.

### B. Vá Lỗi Tương Thích vLLM Remote API Streaming
- **Khắc Phục Lỗi HTTP 400 Bad Request:**
  - Phát hiện và xử lý giới hạn nghiêm ngặt của vLLM / OpenAI API (`too_long: List should have at most 4 items after validation, not 5`).
  - Rút gọn danh sách `stop` tokens trong `app/services/chat.py` từ 5 phần tử xuống đúng 4 phần tử chuẩn xác: `stop=["\n\n\n", "Học viên:", "Sinh viên:", "<|im_end|>]`.
  - Khôi phục thành công luồng Server-Sent Events (SSE) phát token thời gian thực từ mô hình `Qwen/Qwen2.5-Coder-7B-Instruct` host trên GPU Kaggle.

### C. Khảo Thí Thực Tế & Chu Trình Đối Chiếu Benchmark (Empirical Findings)
- **Bản Vá Router Thành Công:**
  - Mở rộng cổng thu nạp Stage 2 NLI Arbiter (`P_course >= 0.15` và `P_oos < 0.75`) trong `app/agent/router.py`, giải cứu thành công các câu hỏi điều hướng lộ trình giáo trình (*"trong playlist"*, *"học bài nào"*) khỏi phân loại sai thành `out_of_scope`.
  - Router Accuracy duy trì mức cao: **97.0% (194/200)** trên bộ Golden Dataset.
- **Bài Học Sống Còn Về Pareto Context Sufficiency & Hồi Quy Ngữ Cảnh:**
  - Tiến hành thử nghiệm ép buộc điều kiện Code AST trên retrieval; sau khi chạy toàn diện bộ Benchmark 200 câu (`stage11_report_2026-10-08_22-39-39.md`), hệ thống phát hiện hiện tượng sụt giảm độ chính xác ở Tier 1 In-Scope (do 43 câu in-scope được dạy kỹ qua Video nhưng chưa có file AST riêng bị future lesson cướp mất).
  - Ngay lập tức khôi phục (revert) `app/services/retrieval.py` về cơ sở Pareto chuẩn mực đã được kiểm chuẩn.
  - Đúc kết chiến lược kết hợp chuẩn: **Phương án 1 (Curriculum Navigation Intent Dispatcher tại ChatService)** giải quyết câu hỏi lộ trình ở tầng sư phạm, kết hợp **Phương án 2 (Data-Centric Code AST Enrichment)** ở tầng dữ liệu.
